《和小光一起学 Python》· 使用说明（电脑版）
==========================================

欢迎使用！这是一套**本地离线的 Python 少儿编程闯关课**：双击即用、不用联网、
不用安装，进度自动存在本机。本版本已关闭激活，打开就能用。

------------------------------------------------------------
一、怎么打开（第一次）
------------------------------------------------------------
把整个文件夹解压到电脑任意位置（桌面、D 盘都行），然后：

  · Windows：双击文件夹里的「双击打开.bat」，会自动弹出浏览器开始学习。
             也可以直接双击 index.html（用 Chrome / Edge 打开）。
  · 苹果 Mac：右键文件夹里的「双击打开.command」→ 选择「打开」（首次双击若被系统拦截，请右键→打开即可）。
              首次可能提示"未知开发者"，去「系统设置 → 隐私与安全性」
              点「仍要打开」即可。
              打开后终端会显示启动信息，并自动弹出浏览器进入课程。
              若浏览器没有自动弹出，请在地址栏手动输入 http://127.0.0.1:8000

  ★ 建议用 Chrome 或 Edge 浏览器，体验最好。

------------------------------------------------------------
二、小朋友怎么学
------------------------------------------------------------
  1. 首页点「📚 学生课程」进入闯关地图，每节课是一张卡片。
  2. 第 1 课直接点开；学完一节后，下一节会显示 🔒，需要家长解锁。
  3. 一节课里有：视频讲解 →「小光讲一讲」语音总结 → 文字讲义（可朗读）
     → 本节单词 → 练习（自动判分）→ 完成本节 → 勋章。
  4. 做练习时如果改错了原始代码，点「🔄 重置」就能恢复初始状态，重新来过。
  5. 刷新页面不会丢进度，已填的答案和当前位置会自动恢复。

------------------------------------------------------------
三、家长怎么用
------------------------------------------------------------
首页带 🛡️ / 📋 的入口需要家长密码（默认 1234）：

  · 📋 家长课程：两节给家长看的入门课（Python 是什么、学习路线图）。
  · 🛡️ 家长园地：设置孩子昵称、语音风格；查看 / 解锁 / 锁定每一节课；
    看学习报告；修改家长密码；导出 / 导入进度备份。

------------------------------------------------------------
四、进度与安全
------------------------------------------------------------
  · 学习进度、昵称、勋章等都存在浏览器里，关掉再打开还在。
  · 换电脑 / 重装：在「家长园地 → 💾 数据备份」导出"我的课程进度.json"，
    到新电脑导入即可。
  · 收到更新：把新版本文件夹整个覆盖到旧文件夹（同名同路径），进度不丢。
  · 忘记家长密码：默认 1234；若改过忘了，先导出进度 → 清除浏览器对该站点
    缓存（密码重置回 1234）→ 再导入进度。

------------------------------------------------------------
五、常见问题
------------------------------------------------------------
  · 双击 index.html 打开是代码？ → 用浏览器打开（右键"打开方式"选 Chrome/Edge）。
  · 视频区空白？ → 该课视频文件缺失，不影响讲义和练习。
  · 听不到朗读 / 音效？ → 检查电脑音量，首次点一下页面允许声音。
  · 代码练习运行没反应？ → 内置 Python 引擎不支持真实文件 / 网络 / 画图库，
    相关章节已用模拟演示，其余都能真跑。
